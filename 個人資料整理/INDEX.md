## 快速申請流程

1. 看到申請表 → 比對上方對照表，確認缺哪幾格
2. 到對應資料夾取文件
3. 新建 `申請檔案/獎項名稱_年份/` 資料夾，把要交的文件複製進去
4. 說「整理」→ 取得最新講師經歷表 Excel

## 給 Claude 的索引提示

**下次 session 開始時讀這兩個檔案就能快速上手：**

1. `INDEX.md`（本檔）— 了解整體架構
2. `PROFILE.md` — 知道庫內現有哪些資料，可即席產出個人文字

**常用操作：**
- 有新檔案要入庫 → 說「入庫」
- 要寫任何形式的自我介紹 → 說「寫自介 [用途]」
- 確認目前庫裡有什麼 → 說「現在有什麼」
- 更新講師經歷表 → 說「整理」
- 更新某個專案摘要 → 說「更新專案 [名稱]」
- 新增分類規則 → 說「新增分類 [描述]」

**找特定資料：**
- 講師經歷 → `講師經歷表.xlsx` 或說「整理」重新產生
- 基本文件 → `個人基本資料/` 的 A0–G 子資料夾
- 研習公文原始 PDF → `研習公文/YYMMDD活動名稱/`
- 專案資訊 → `專案紀錄/專案名稱/_專案摘要.md`
- 申請資料包 → `申請檔案/`
- 分類規則 → `分類規則.md`
