# 分類規則

Claude 入庫前讀這個檔案，依此決定每個檔案放哪、怎麼改名。
可隨時新增、修改、刪除規則列。

## 分類代號表

| 代號 | 類型描述 | 目標資料夾 | 備註 |
|-----|---------|-----------|------|
| A0 | 個人簡介（一頁簡報、自介 PDF、履歷表） | 個人基本資料/00_個人簡介/ | 保留所有歷史版本，用日期命名 |
| A  | 個人基本資料（學歷/教師資格/考核/聘書/獎懲） | 個人基本資料/對應子資料夾/ | Claude 依內容細分子資料夾 |
| B  | 研習講師公文 | 研習公文/ | 一份公文一個 YYMMDD 子資料夾 |
| C  | 進修研習（學員身份） | 進修研習/ | |
| D  | 教學成果（教材/課程設計/數位工具） | 教學成果/ | |
| E  | 輔導紀錄（學習扶助/競賽指導） | 輔導紀錄/ | |
| F  | 行政服務（職務/委員/評審） | 行政服務/ | |
| G  | 得獎榮譽（個人或指導學生） | 得獎榮譽/ | |
| H  | 影片 | 不移動，記連結到 PROFILE.md 第9節 | 檔案太大，只記錄 |
| I  | 專案文件（申請計畫/成果報告/展示素材） | 專案紀錄/對應專案/申請展示/ | 本體留在原始資料夾 |
| Z  | 不確定 | _待確認/ | 下次入庫時再問 |

## 命名格式

學年度_文件類型_機構或說明_吳國榮.副檔名

範例：
- 114_成績考核通知書_更寮國小_吳國榮.jpg
- 202505_個人簡介一頁簡報_吳國榮.pptx
- 112_申請計畫書_學習扶助閱讀教學系統.pdf

個人簡介文件用西元年月（YYYYMM），其他官方文件用民國學年度。

## 調整規則的方式

1. 說「新增分類 [描述]」→ Claude 更新這個檔案
2. 入庫過程中說「這類要獨立一個資料夾」→ Claude 當場修改
3. 直接編輯這個檔案，下次入庫自動生效
