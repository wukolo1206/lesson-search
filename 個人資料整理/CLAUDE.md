# 個人資料整理

吳國榮講師個人研習經歷自動整理系統。

## 🔑 觸發指令

**使用者說「整理」時，立刻執行：**

```
python "d:\test ch\個人資料整理\update_all.py"
```

執行後回報：新增幾筆、總筆數、有無錯誤。

## 關鍵路徑

| 項目 | 路徑 |
|------|------|
| 主腳本 | `update_all.py` |
| PDF 公文資料夾 | `研習公文\` |
| 輸出 Excel | `講師經歷表.xlsx` |
| 輸出 Markdown | `講師經歷表.md` |
| JSON 資料庫 | `output_lectures.json` |

## 流程架構

```
研習公文\ 新增 PDF
        ↓
  update_all.py
  ├── extract_lectures.py      （掃描資料夾，合併模式）
  ├── parse_schedule_pdfs.py   （課程表型 PDF，多場次）
  └── generate_output.py       （→ Excel + Markdown）
        ↓
  講師經歷表.xlsx（Google Drive 自動同步）
```

## 新增 PDF 注意事項

- 一份公文放一個子資料夾，以 `YYMMDD` 或活動名稱命名
- 若為整份課程表（含多場次），需手動加入 `parse_schedule_pdfs.py` 的 `SCHEDULE_PDFS` 清單
- 放好後說「整理」即可

## 🔑 v2 觸發指令

### 入庫
**使用者說「入庫」時，立刻執行：**
1. 讀取 `分類規則.md`（取得最新分類邏輯）
2. 列出 `_inbox/` 所有檔案（跳過 README.md）
3. 對每個檔案，最多問 2 個問題：
   - Q1：「這是什麼？」（依分類規則給代號選項）
   - Q2：「哪個學年度？」（檔名看不出來時才問）
4. 決定目標資料夾與新檔名（依分類規則的命名格式）
5. 移檔＋改名
6. 若異動 A-G → 更新 `個人基本資料/個人基本資料索引.md`
7. 更新 `PROFILE.md` 對應段落（更新狀態標記與內容）
8. 回報：「入庫 N 筆，跳過 N 筆（原因）」
9. 若 `_待確認/` 有檔案，一併列出詢問

**影片處理**：本體不移動，只在 PROFILE.md 第9節新增連結紀錄。

---

### 更新專案
**使用者說「更新專案 [專案名稱]」時：**
1. 讀取 `專案紀錄/[專案名稱]/_專案摘要.md`
2. 詢問需要更新哪些欄位（狀態/期間/連結/亮點）
3. 更新 `_專案摘要.md`
4. 更新 `PROFILE.md` 第10節對應列

---

### 寫自介
**使用者說「寫自介 [用途]」時：**
1. 讀取 `PROFILE.md`（只讀「有文件支撐」的段落，不使用「待補」段落）
2. 依用途調整長度、重點、語氣產出文字
3. 存到 `PROFILE.md` 素材庫對應區段

用途範例：`講師簡介50字` / `講師簡介150字` / `申請特殊優良教師用` / `演講開場講者介紹` / `email開頭自我介紹` / `個人簡歷表格`

---

### 現在有什麼
**使用者說「現在有什麼」時：**
讀取 `PROFILE.md`，用一頁摘要回報：
- 哪些段落「有文件支撐」、哪些「待補」
- 專案清單與狀態
- 素材庫已有哪些版本

---

### 新增分類
**使用者說「新增分類 [描述]」時：**
在 `分類規則.md` 分類代號表新增一列，代號接續現有最大代號之後。

---

## 不能動的地方

- `output_lectures.json` — 唯一資料來源，勿手動清空
- `generate_output.py` 的 `SHEET_ID` — Google Sheet 對應 ID
- `extract_lectures.py` 的合併邏輯 — 避免覆蓋行事曆補入的資料
