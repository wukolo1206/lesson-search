### 1. 專案名稱 *
從備課到遷移驗證：AI 輔助建置的學習扶助閱讀教學支援系統

---

### 2. 計畫內容 ( Plan ) *
**(撰寫重點：簡述教學流程、AI 工具如何融入、教師引導與學生產出)**

本計畫打造一個以「教師教學循環」為主軸的學習扶助支援系統，整合備課、授課與測驗三階段流程：
1. **備課查詢**：教師透過年級、認知歷程、文本類型與教學策略等維度，快速檢索適用於學習扶助標準的閱讀教材與試題。
2. **課堂引導**：系統內建即時簡報模式，左右對照展示文本與試題，教師無須製作 PPT 即可直接投影引導學生。
3. **學生產出與概念遷移**：課後發布「遷移驗證作答」，學生登入載具作答，由 AI 判定學生是否能將剛學到的閱讀策略成功遷移至陌生文本，系統並提供即時成績看板。

**AI 工具融入方式**：
AI 扮演「擴展題庫規模並維持品質」的引擎（非直接取代教師教學）。使用 Claude (Anthropic API) 進行三層次處理：
1. 先依照教育部官方 PDF 教材進行原始題庫「健檢」，確保認知歷程標籤正確。
2. 自動生成與原題考點同構的「遷移題目」。
3. 採用 AI 自動進行多維度品質審查（考點同構、誘答一致、策略適用、基礎適配），並產出修改建議。

---

### 3. 資源需求 ( 經費/工具 )
**(撰寫重點：外聘講師費、材料費、AI 帳號額度、平板/投影設備...)**

1. **AI 帳號額度 (Claude Pro 訂閱 / API 費用)**：
   - **為何需要 Claude Pro / API**：本系統需處理高達數百篇原始長文與官方 PDF 教材，並為每道題目進行多維度的深度審核。相較於一般 AI 網頁版介面無法一次讀取大量資料夾結構與檔案，透過 Claude Pro 授權的 Claude Code (命令列專案工具) 環境，我們能讓 AI 直接存取並橫跨讀取專案內龐大的教材資料庫與試題 JSON 檔。同時，免除免費版嚴苛的對話次數與上下文 (Context Window) 限制，確保能無中斷地完成高達 585 道遷移試題的自動化品管與生產。
2. **硬體設備**：
   - 教室端：需具備投影設備與教師用電腦（用於課堂簡報模式投影）。
   - 學生端：需具備平板電腦或 Chromebook 等連網載具（用於讓學生進行遷移驗證測驗作答）。
3. **軟體與開發環境**：全系統架構於 Google Workspace (Google Apps Script、Google Sheets) 及靜態網頁前端，不需額外伺服器主機架設經費；教材電子檔分析可免費使用開源 Python 模組辦理。

---

### 4. 預計產出 ( Output ) *
**(撰寫重點：教案、教學影片、學生作品集、提示詞庫、評量工具...)**

1. **數位評量工具與教學系統**：一套無需安裝軟體、純瀏覽器介面的「學習扶助閱讀教學支援系統」（含備課、簡報、作答與批改看板模組）。
2. **系統性學習扶助閱讀題庫**：包含 195 道原始優質試題，並經由 AI 擴充產出 585 道遷移試題，總計 780 道（完整覆蓋國小三至六年級、4 個認知歷程層次、19 種教學策略）。
3. **教學提示詞庫與審查報告**：紀錄 AI 在檢驗試題與生成遷移題目時的「Prompt 控制提示詞庫」，以及針對各道題目常見學生迷思所整理的「AI 審閱反饋報告」。

---

### 5. 預計成效 ( Effectiveness ) *
**(撰寫重點：建議用 SMART 原則，包含可量化指標)**

1. **大幅提升備課效率（Time-saving）**：教師尋找特定閱讀策略與對應試題的備課時間，由過去單題需 15 分鐘跨網頁搜尋，縮短至 30 秒內一鍵產出結果（效率提升達 96%）。
2. **充實題庫發行規模（Scalability）**：藉由 AI 生成與擴展題庫，讓國小學習扶助題庫總產能提升 300%（從 195 題增至 585 題以上），彌補過去「讓學生將策略遷移至陌生文本」練習資源不足的缺口。
3. **自動化審查效能躍升（Efficiency）**：AI 題庫審查速度達每題約 3 秒完成多維度分析，相較傳統人工動輒花費 2-3 天逐題檢視，大幅縮短 90% 以上檢核時間。
4. **即時診斷學力遷移（Measurability）**：透過「線上遷移驗證作答」系統，教師能 100% 掌握全班學生對該閱讀策略的吸收度與遷移能力，提升「即時反饋」的診斷品質。
