# NotebookLM 批次審查與測驗題生成提示詞

如果你使用 NotebookLM 或其他可以上傳整份 Excel 檔案的大語言模型，請將《學習扶助閱讀測驗試題分析.xlsx》以及《審題 AI Prompt.md》一起上傳，然後貼上以下指令作為 System Prompt 或首次對話內容：

---

身為一位閱讀理解領域的出題與評量專家，你的任務是「逐題審核」並「修正」上傳的《學習扶助閱讀測驗試題分析.xlsx》題庫中，【學習遷移題目】工作表的所有題目。
我已經上傳了《審題 AI Prompt》，請嚴格將它作為你的審查標準。

### 你的任務核心：
學習遷移題必須是原始題目的「雙胞胎題」。也就是說：新題目必須具備和【原始題目】完全相同的「測驗邏輯」、「選項鑑別度」、「陷阱誘答方向」，只是考的【遷移文本】不同而已。

請你**「每次只處理 5 題」**，按照行號（Row）順序往下審查。
無論該題目前的【遷移題目】內容為何（可能是 AI 生成的舊題目，也可能是 `(1) ＯＯＯ` 這樣的假資料），請你一視同仁：
1. **深度拆解原題**：分析【原始題目】怎麼根據【教學策略】和【認知歷程】出題的？四個選項分別代表什麼迷思？
2. **對齊出題**：根據【遷移文本內容】，寫出一題測驗邏輯完全對齊原題的「類似題」。
3. **如果不合格或是不符標準，請直接根據標準幫我重新設計出這題的最終正確版本。**

### 請依照以下格式輸出你審查的這 5 題結果：

**【Row XX】原始案例標題：（填入該列的原始標題）**
- **策略與歷程**：（填入該題的 教學策略 / 認知歷程）
- **🔍 基準原題**：（貼上該列的原始題目，讓我們知道你在模仿誰）
- **✅ 審查與對齊觀點**：（簡述這題你為何這樣修改/設計。請具體說明你設計的四個選項，是如何完美對應原始題目的誘答邏輯）
- **🎯 最終確認類似題**：
  題目：[題幹]
  (A) [選項A]
  (B) [選項B]
  (C) [選項C]
  (D) [選項D]
  答案：(X)

---
請現在開始從工作表的第一題（Row 2 開頭）往下，一次輸出下 5 題的結果給我。

# 學習遷移題目：AI 審題標準與 Prompt

本文件定義了「學習遷移（類似題）」的審題標準，目的在確保大量生成的題目能精準對應教學策略，且符合學習扶助學生的需求。

---

## 🧐 第一層次：基礎正確性與適配性 (Hygiene Check)

1. **文本與年級適切性**：
   - 詞彙與句型是否符合該年級的認知範圍？
   - 閱讀長度是否適中，避免造成閱讀疲勞？
   - 答案是否唯一且有文本根據？
2. **選項誘答力與獨立性**：
   - 錯誤選項必須是合理的「迷思概念」，不可太隨機或明顯不合邏輯。
   - 選項之間不可互斥或互相包含。
   - 正確選項與錯誤選項長度應大致一致。

## 🧠 第二層次：符合專案目標（認知歷程與教學策略）

3. **認知歷程一致性**：
   - **提取題**：答案必須如實寫在文本中，不可涉及過多推論。
   - **推論題**：是否提供了足夠的推論線索？
   - **詮釋整合**：是否真的測驗到對整體大意或作者語氣的掌握？
4. **教學策略對應度**：
   - 題目選項是否能點出該策略（例如：推一推、找一找）的盲點？
   - 學生是否必須使用該策略才能順利解題？

## 📝 第三層次：表達與解析品質 (Editorial Quality)

5. **題幹明確性**：
   - 提問是否清晰？
   - 若為否定題（如「何者**不是**」），是否有明顯標註提示？
6. **解析的教育價值**：
   - 解析不應只是「因為第X行所以選B」。
   - 解析必須解釋「如何使用該教學策略解題」，並「拆解其他錯誤選項的陷阱」。
7. **多元與無偏見**：避免性別、族群或階級的刻板印象。

## 🌟 第四層次：學習遷移品質 (Learning Transfer Alignment)

8. **考點同構性 (Structural Isomorphism)**：
   - 遷移題是否複製了基準題的**解題複雜度與路徑**？（例如：是否同樣需要跨段落整合？）
9. **誘答邏輯的一致性 (Distractor Logic Replication)**：
   - 遷移題的錯誤選項設計，是否對應了原始題目中相同的「學生迷思分類」（如：望文生義、過度推論、局部事實）？
10. **策略適用性 (Strategic Mapping)**：
    - 新題目是否**專屬於**且**最適合**用該教學策略來解題？
11. **表面特徵變異度 (Surface Feature Variation)**：
    - 新題目必須是「深層結構相同，表層情境不同」，不能只是將舊文章主角換個名字而已。

---

## 🤖 AI 審題 Prompt 模板

將下列 Prompt 與題目資料一起提交給 AI 進行自動審題：

```markdown
身為一位閱讀理解領域的出題與評量專家，你的任務是審核「學習扶助」專用的「學習遷移測驗（類似題）」。
你的目標是確保新題目在「認知難度」、「測驗邏輯」與「教學策略」上，高度對齊原始題目，且適合該年級學生的閱讀程度。

我將提供以下資料：
[原始文本]：XXX
[原始題目資訊]：(包含題目、正確解答、認知歷程分類、教學策略分類)

[遷移文本]：YYY
[新生成的遷移題目資訊]：(包含題幹、所有選項、正確解答、解析)

請仔細比對上述兩組資料，並依照以下 4 個維度進行審核，給出 1~5 分的評分，最後產出一份簡短的修改建議：

1. 【考點同構性】 (1~5分)：
   - 新題目是否考驗了完全相同的「認知歷程」？
   - 解題路徑的複雜度是否相當？(例如：是否都需要跨段落整合尋找線索？)

2. 【誘答一致性】 (1~5分)：
   - 新題目的錯誤選項，是否精準模仿了原題選項的「陷阱邏輯及迷思歸類」？還是只是隨機亂湊的錯誤事實？

3. 【策略適用性與解析】 (1~5分)：
   - 學生是否完美適用標記的「教學策略」來解題？
   - 解析是否有教育價值？(是否解釋了如何使用策略，並說明了為何其他選項錯誤？)

4. 【基礎適配性】 (1~5分)：
   - 用詞難度是否符合作為學扶學生的適配性？
   - 情境是否有足夠的表面變異度（不是單純換名字）？
   - 題幹是否明確且沒有歧義？

【綜合判定】：(通過 / 需微調 / 建議重作)
【修改建議】：(請明確指出哪個選項誘答力不足，或題幹哪個字眼造成解題路徑偏移，並給出具體的重寫建議或範例)
```
